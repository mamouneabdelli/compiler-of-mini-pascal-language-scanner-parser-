## Overview

This project implements the front-end of a compiler for **MiniPascal-Fr (MP-FR)**, a simplified Pascal dialect using French keywords (`programme`, `debut`, `fin`, `si`, `alors`, `tantque`, `pour`, etc.).

The pipeline consists of two stages:

1. **Scanner (Lexical Analyzer)** — reads MP-FR source code and produces a stream of tokens.
2. **Parser (Syntax Analyzer)** — performs recursive descent parsing on the token stream, validating the program against the MP-FR grammar and reporting the grammar rules applied.

## BNF Notation Reference

The grammar below follows Backus Normal Form (BNF) with the conventions described below.

| Notation         | Meaning                                                             |
| ---------------- | -------------------------------------------------------------------- |
| `::=`            | "is defined as" (sometimes written `=`)                             |
| `<NonTerminal>`  | Non-terminal symbol, written between angle brackets                |
| lowercase word   | Terminal symbol (keyword or literal)                                |
| `a b`            | Concatenation — `a` followed by `b`                                 |
| `a / b`          | Choice — either `a` or `b`                                          |
| `[a]`            | Option — zero or one occurrence of `a`                              |
| `a*` or `{a}`    | Repetition — zero or more occurrences of `a`                        |

## MP-FR Grammar

```bnf
<ProgrammePascal> ::= programme <NomProgramme> ; <Corps> .

<Corps> ::= [<PartieDéfinitionConstante>] [<PartieDéfinitionVariable>] <InstrComp>

<PartieDéfinitionConstante> ::= constante <DéfinitionConstante> {<DéfinitionConstante>}
<DéfinitionConstante>       ::= <NomConstante> = <Constante> ;

<PartieDéfinitionVariable> ::= variable <DéfinitionVariable> {<DéfinitionVariable>}
<DéfinitionVariable>       ::= <GroupeVariable> ;
<GroupeVariable>           ::= <NomVariable> {, <NomVariable>} : <NomType>

<NomVariable> ::= <Nom>
<Nom>         ::= <Lettre> <Chiffre> {<Lettre> | <Chiffre>}
<Lettre>      ::= "A" | "B" | ... | "Z" | "a" | ... | "z"
<Chiffre>     ::= 0 | 1 | ... | 9

<NomType> ::= entier | reel

<NomConstante>  ::= <Nom>
<Constante>     ::= <Nombre> | <NomConstante>
<NomProgramme>  ::= <Nom>

<Nombre> ::= <Chiffre> {<Chiffre>}
           | <Chiffre> <Chiffre> {<Chiffre>} . <Chiffre> {<Chiffre>}

<InstrComp> ::= debut <Instruction> {; <Instruction>} fin

<Instruction> ::= <InstructionAffectation>
                | <InstructionSi>
                | <InstructionTantque>
                | <InstructionRepeter>
                | <InstructionPour>
                | <Vide>

<InstructionAffectation> ::= <NomVariable> := <Expression>

<Expression> ::= <ExpressionSimple> [<OperateurRelationnel> <ExpressionSimple>]

<OperateurRelationnel> ::= = | <> | < | > | <= | >=

<ExpressionSimple> ::= [<OperateurSigne>] <Terme> {<OperateurAddition> <Terme>}

<OperateurSigne>    ::= + | -
<OperateurAddition> ::= + | - | ou

<Terme> ::= <Facteur> {<OperateurMult> <Facteur>}

<OperateurMult> ::= * | div | mod | et

<Facteur> ::= <Constante> | <NomVariable> | ( <Expression> )

<InstructionSi>      ::= si <Expression> alors <Instruction> [sinon <Instruction>]

<InstructionTantque> ::= tantque <Expression> faire <Instruction>

<InstructionRepeter> ::= repeter <Instruction> jusqu'a <Expression>

<InstructionPour>    ::= pour <NomVariable> allant de <Constante> a <Constante> [pas <Constante>] faire <Instruction>

<Vide> ::= ''
```

## Tasks

### Task 1 — Scanner (`Scanner2025`)

The scanner performs lexical analysis on MP-FR source code.

**Responsibilities:**

- Read the source code file.
- Generate a **`TOKEN`** file containing the full sequence of recognized tokens.
- Display on screen:
  - The sequence of recognized tokens.
  - The contents of the **symbol table**.
  - Any lexical errors, with their type.

### Task 2 — Recursive Descent Parser (`Parser2025`)

The parser performs syntax analysis using the output of the scanner.

**Responsibilities:**

- Consume the `TOKEN` file generated by the scanner.
- Generate a **`RULE`** file containing the sequence of grammar rules applied.
- Display on screen:
  - The sequence of grammar rules used during parsing.
  - Any syntax errors, with their type.

## Usage

1. **Run the scanner** on an MP-FR source file:

   ```bash
   python Scanner2025.py path/to/source.mpfr
   ```

   This generates a `TOKEN` file and prints the token stream, symbol table, and any lexical errors.

2. **Run the parser** on the generated tokens:

   ```bash
   python Parser2025.py TOKEN
   ```

   This generates a `RULE` file and prints the applied grammar rules and any syntax errors.
